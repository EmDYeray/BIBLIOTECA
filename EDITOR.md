# Editor de escenas y contenido en Linux

Ejecuta `./editor/launch.sh` en una sesión gráfica con Python 3 y Tkinter. El editor guarda el proyecto en `editor/content.json`; importa portadas PNG a `editor/covers/`. La vista superior trabaja en metros y permite crear salas, colocar objetos, editar posición, rotación, escala, material y propiedades de colisión, duplicar, borrar, deshacer y rehacer. El botón **Probar en la app** guarda `assets/content/scene.json` y abre el renderer OpenGL nativo, por lo que la geometría se prueba con el mismo código de la aplicación. Si todavía no existe el ejecutable Linux, compílalo con `make -j2`.

Para cada libro se pueden preparar título y páginas en español e inglés por separado. Puede extraer el texto de un PDF con `pdftotext` (paquete poppler-utils) para que lo revises y repartas entre páginas. No se genera ni traduce texto automáticamente: el autor revisa cada versión contra sus PDF originales. Consulta `CONTENT_FORMAT.md` para el esquema compartido.

**Exportar paquete** crea un ZIP con textos y portadas y un `manifest.json` con SHA-256. **Publicar en GitHub** envía ese ZIP a la rama `library-content` del repositorio `EmDYeray/Library-of-Stars` mediante `gh` y Git. Requiere `gh auth login` y acceso de escritura. También puedes usar `python3 tools/publish-content.py ruta/al/paquete.zip` desde la raíz. La app Android consulta el manifiesto al iniciarse, verifica tamaño y SHA-256, descarga el paquete en almacenamiento privado y lo utiliza en el siguiente inicio; si no hay conexión, usa el contenido anterior. Para recibir actualizaciones, primero hay que instalar una versión de Android que incluya este lector.

Las salas adicionales, los objetos básicos, sus colisiones y las posiciones sobrescritas de libros ya se leen en tiempo de ejecución. **Limitación actual:** el editor principal sigue usando una vista superior; la vista OpenGL se abre como ventana de prueba y todavía no permite manipular gizmos directamente. Las conexiones aún no recortan puertas en los muros generados, y los portales no ejecutan teletransporte. La búsqueda NASA usa el índice de GitHub del repositorio oficial NASA-3D-Resources; un GLB todavía necesita conversión, optimización y verificación del pop-up antes de publicarlo. En Linux, `./ejecutable.sh` consulta el paquete antes de abrir la biblioteca y conserva el contenido local si no hay conexión. La actualización automática para la distribución Windows todavía está pendiente.
