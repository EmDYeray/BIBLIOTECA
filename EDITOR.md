# Editor de contenido en Linux

Ejecuta `./editor/launch.sh` en una sesión gráfica con Python 3 y Tkinter. El editor guarda el proyecto en `editor/content.json`; importa portadas PNG a `editor/covers/`. Permite crear un plano con salas, estanterías, fogata, faroles, mesas, sillas y bancos, y colocar referencias a los 59 libros actuales. Para cada libro se pueden preparar título y páginas en español e inglés por separado. Puede extraer el texto de un PDF con `pdftotext` (paquete poppler-utils) para que lo revises y repartas entre páginas. No se genera ni traduce texto automáticamente: el autor revisa cada versión contra sus PDF originales.

**Exportar paquete** crea un ZIP con textos y portadas y un `manifest.json` con SHA-256. **Publicar en GitHub** envía ese ZIP a la rama `library-content` del repositorio `EmDYeray/Library-of-Stars` mediante `gh` y Git. Requiere `gh auth login` y acceso de escritura. También puedes usar `python3 tools/publish-content.py ruta/al/paquete.zip` desde la raíz. La app Android consulta el manifiesto al iniciarse, verifica tamaño y SHA-256, descarga el paquete en almacenamiento privado y lo utiliza en el siguiente inicio; si no hay conexión, usa el contenido anterior. Para recibir actualizaciones, primero hay que instalar una versión de Android que incluya este lector.

El plano de salas y los enlaces NASA se guardan en el proyecto y se exportan. **Limitación actual:** el cliente aún tiene dos salas fijas y 59 posiciones definidas en C++; las salas, los muebles nuevos, las posiciones y los modelos NASA del editor todavía no se renderizan dentro de la app. La búsqueda NASA usa el índice de GitHub del repositorio oficial NASA-3D-Resources; abrir un resultado permite inspeccionarlo, pero un GLB necesita conversión y verificación del pop-up antes de publicarlo. En esta versión sí se actualizan textos, títulos y portadas PNG de los libros existentes. En Linux, `./ejecutable.sh` consulta el paquete antes de abrir la biblioteca y conserva el contenido local si no hay conexión. La actualización automática para la distribución Windows todavía está pendiente.
